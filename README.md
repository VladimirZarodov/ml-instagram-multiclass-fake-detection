# Instagram Multi-Class Fake Account Detection / Многоклассовая классификация фейковых аккаунтов Instagram

[![Python](https://img.shields.io/badge/Python-3.12-blue)](https://www.python.org/)

Проект посвящён многоклассовой классификации аккаунтов Instagram на четыре категории: **Real**, **Bot**, **Scam** и **Spam** с использованием методов машинного обучения.

## О проекте

Цель проекта — исследовать возможность автоматической классификации Instagram-аккаунтов по типу профиля на основе их характеристик и показателей активности.

В работе используется датасет **LIMFADD (LLM-enabled Instagram Multi-Class Fake Account Detection Dataset)**, содержащий четыре класса аккаунтов:

* **Real** — реальные аккаунты;
* **Bot** — автоматизированные аккаунты;
* **Scam** — мошеннические аккаунты;
* **Spam** — спам-аккаунты.

В ноутбуке [`Multi-Class_Fake_Detection.ipynb`](./Multi-Class_Fake_Detection.ipynb) реализован полный цикл машинного обучения:

* загрузка и исследование данных;
* очистка и предобработка;
* кодирование признаков;
* создание новых признаков;
* масштабирование;
* отбор наиболее информативных признаков;
* обучение пяти моделей машинного обучения;
* оценка качества классификации;
* исследование регулируемых параметров;
* подбор гиперпараметров с помощью `GridSearchCV`;
* сравнение различных структур набора признаков;
* выбор итоговой модели;
* прогноз на независимой выборке.

## Данные

Используется файл [`LIMFADD.csv`](./LIMFADD.csv). Источник [`https://www.tapadhirdas.com/das-lab/datasets/limfadd`](https://www.tapadhirdas.com/das-lab/datasets/limfadd).

Исходный набор содержит **15 000 объектов** и следующие признаки:

| Признак             | Описание                                            |
| ------------------- | --------------------------------------------------- |
| Followers           | Количество подписчиков                              |
| Following           | Количество подписок                                 |
| Following/Followers | Отношение количества подписок к числу подписчиков   |
| Posts               | Количество публикаций                               |
| Posts/Followers     | Отношение количества публикаций к числу подписчиков |
| Bio                 | Наличие описания в профиле                          |
| Profile Picture     | Наличие фотографии профиля                          |
| External Link       | Наличие внешней ссылки                              |
| Mutual Friends      | Количество общих друзей                             |
| Threads             | Наличие аккаунта в Threads                          |
| Labels              | Целевая переменная: Real / Bot / Scam / Spam        |

### Классы целевой переменной

* **Real** — реальные аккаунты пользователей;
* **Bot** — автоматизированные аккаунты;
* **Scam** — мошеннические аккаунты;
* **Spam** — аккаунты, предназначенные для распространения спама.

## Предобработка данных

На этапе предварительной обработки:

1. Значения `#DIV/0!` заменяются на `NaN`.
2. Признаки `Following/Followers` и `Posts/Followers` переводятся в числовой формат.
3. Строки с пропущенными значениями удаляются.
4. Бинарные признаки `Bio`, `Profile Picture`, `External Link` и `Threads` кодируются значениями `0/1`.
5. Целевая переменная `Labels` кодируется с помощью `LabelEncoder`.
6. Для признака `Posts` создаётся дополнительный категориальный признак `Activity_Level`.
7. Создаётся дополнительный числовой признак:

```text
Engagement_Ratio = (Posts + Mutual Friends) / (Followers + 1)
```

После удаления строк с пропущенными значениями остаётся **14 434 объекта**.

В итоговой матрице признаков используется **13 числовых признаков**.

Для базового обучения применяется разбиение:

```text
80% — обучающая выборка
20% — тестовая выборка
```

Для экспериментов используется отдельное разбиение:

```text
60% — обучение и подбор параметров
20% — тестовая выборка
20% — независимая новая выборка
```

Для моделей, чувствительных к масштабу признаков, используется `StandardScaler`.

## Используемые модели

В проекте исследуются пять алгоритмов машинного обучения:

1. **K-Nearest Neighbors (kNN)**
2. **Decision Tree**
3. **Random Forest**
4. **CatBoost**
5. **Multilayer Perceptron (MLP)**

### Базовые параметры моделей

| Модель        | Основные параметры                            |
| ------------- | --------------------------------------------- |
| kNN           | `n_neighbors=5`                               |
| Decision Tree | `max_depth=10`                                |
| Random Forest | `n_estimators=100`, `max_depth=12`            |
| CatBoost      | `iterations=300`, `depth=6`                   |
| MLP           | `hidden_layer_sizes=(64, 32)`, `max_iter=300` |

## Оценка качества

Для оценки моделей используются следующие метрики многоклассовой классификации:

* **Accuracy**
* **Precision**
* **Recall**
* **F1-score**
* **ROC-AUC**

Для `Precision`, `Recall` и `F1-score` используется усреднение `macro`, при котором каждый класс имеет одинаковый вес.

Для ROC-AUC используется стратегия **One-vs-Rest (OVR)**.

Также используются:

* `classification_report`;
* матрица ошибок (`confusion matrix`);
* сравнительные графики метрик.

## Результаты базового обучения

После обучения моделей на базовой структуре данных с 8 отобранными признаками получены следующие результаты:

| Модель            | Accuracy   | Macro F1   | ROC-AUC    |
| ----------------- | ---------- | ---------- | ---------- |
| **Random Forest** | **0.9716** | **0.9723** | **0.9987** |
| Decision Tree     | 0.9681     | 0.9690     | 0.9965     |
| CatBoost          | 0.9678     | 0.9686     | 0.9986     |
| MLP               | 0.9501     | 0.9503     | 0.9967     |
| kNN               | 0.9428     | 0.9430     | 0.9930     |

На данном этапе наибольшее значение `Macro F1` получил **Random Forest**.

## Подбор гиперпараметров

В рамках исследования для каждой модели выполняется перебор гиперпараметров с использованием `GridSearchCV` и трёхкратной стратифицированной кросс-валидации.

Для настройки используется `F1-score Macro`.

Рассматриваются, в частности, следующие параметры:

| Модель        | Исследуемые параметры                  |
| ------------- | -------------------------------------- |
| kNN           | `n_neighbors`, `weights`               |
| Decision Tree | `max_depth`, `min_samples_leaf`        |
| Random Forest | `n_estimators`, `max_depth`            |
| CatBoost      | `iterations`, `depth`, `learning_rate` |
| MLP           | `hidden_layer_sizes`, `alpha`          |

Лучшие конфигурации определяются отдельно для двух вариантов структуры данных.

## Изменение структуры данных

Исследуются два варианта набора признаков:

### Вариант A — 8 признаков

После отбора наиболее информативными оказались:

```text
Followers
Following
Posts
Bio
External Link
Mutual Friends
Threads
Activity_Level_High
```

### Вариант B — 13 признаков

Используются все доступные числовые признаки, включая созданный признак:

```text
Engagement_Ratio
```

Результаты показали, что изменение структуры признаков влияет на разные алгоритмы по-разному. Например, добавление признаков повысило `Macro F1` у kNN примерно на **0.0143**, а у MLP примерно на **0.0096**, тогда как для Random Forest показатель немного снизился примерно на **0.0010**.

## Результаты после подбора параметров

Наилучшие результаты на тестовой выборке среди настроенных моделей:

```text
F1-score Macro = 0.9762
```

```text

```

Для итоговой проверки модели используется независимая выборка из **2 887 объектов**, которая не использовалась при обучении и подборе параметров.

Выбранная модель `Random Forest` на всех 13 признаках показала:

| Метрика           | Значение   |
| ----------------- | ---------- |
| Accuracy          | **0.9726** |
| Precision (Macro) | **0.9732** |
| Recall (Macro)    | **0.9736** |
| F1-score (Macro)  | **0.9732** |
| ROC-AUC (OVR)     | **0.9986** |

Полученные результаты показывают, что модель сохраняет высокое качество классификации и на данных, которые не использовались при её обучении и настройке.
