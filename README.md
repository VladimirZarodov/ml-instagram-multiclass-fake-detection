Проект посвящён многоклассовой классификации аккаунтов Instagram на четыре категории: **Real**, **Bot**, **Scam** и **Spam** — с использованием моделей машинного обучения.

## 📌 О проекте

Большинство существующих датасетов для детекции фейковых аккаунтов являются бинарными (Real / Fake) и не позволяют различать типы фейковых аккаунтов. Данный проект использует датасет **LIMFADD** (LLM-enabled Instagram Multi-Class Fake Account Detection Dataset), который включает четыре класса и позволяет более глубоко понять поведенческие паттерны каждого типа аккаунтов.

В ноутбуке [`Multi-Class_Fake_Detection`](./Multi-Class_Fake_Detection.ipynb)  реализован полный пайплайн: загрузка и очистка данных, кодирование признаков, масштабирование, обучение и сравнение трёх моделей.


## 📊 Данные

Используется файл [`LIMFADD`](./LIMFADD.csv), содержащий следующие признаки:

| Признак | Описание |
|---------|----------|
| Followers | Количество подписчиков |
| Following | Количество подписок |
| Following/Followers | Отношение подписок к подписчикам |
| Posts | Количество публикаций |
| Posts/Followers | Отношение публикаций к подписчикам |
| Bio | Наличие описания в профиле (Yes/No) |
| Profile Picture | Наличие аватара (Yes/No) |
| External Link | Наличие внешней ссылки (Yes/No) |
| Mutual Friends | Количество общих друзей |
| Threads | Наличие аккаунта в Threads (Yes/No) |
| **Labels** | **Целевая переменная:** Real / Bot / Scam / Spam |

### Классы целевой переменной

- **Real** — настоящие аккаунты реальных пользователей;
- **Spam** — аккаунты, распространяющие однотипные сообщения или ссылки;
- **Scam** — мошеннические аккаунты с фишинговыми ссылками;
- **Bot** — автоматизированные аккаунты с ненормальной активностью.

## 🧠 Методология

1. **Предобработка данных:**
   - Бинарные категориальные признаки (`Bio`, `Profile Picture`, `External Link`, `Threads`) закодированы в 0/1.
   - Целевая переменная `Labels` закодирована через `LabelEncoder` в 0/1/2/3.
   - Некорректные значения (`#DIV/0!`) заменены на `NaN` и удалены.
   - Данные разделены на обучающую и тестовую выборки в пропорции 80/20 (`random_state=42`).
   - Признаки нормализованы с помощью `StandardScaler`.

2. **Обучение моделей:**
   - **Random Forest** (`n_estimators=100`)
   - **SVM** (`kernel='rbf'`, `C=1.0`, `gamma='scale'`)
   - **KNN** (`n_neighbors=5`)

3. **Оценка качества:**
   - Accuracy, precision, recall, f1-score по каждому классу.
   - Визуальное сравнение точности на обучающей и тестовой выборках.

## 📈 Результаты

| Модель | Accuracy (test) | Macro F1 |
|--------|-----------------|----------|
| **Random Forest** | **0.9688** | **0.97** |
| SVM | 0.9550 | 0.96 |
| KNN | 0.9626 | 0.96 |

Лучший результат показал **Random Forest** с точностью **96.9%** на тестовой выборке.
